# Store assets

Everything here is captured from the real extension UI on an original sample article, so there's no third-party branding or copyrighted text in the images.

## Chrome Web Store (`chrome/`)

| Dashboard field | File | Size |
| --- | --- | --- |
| Store icon | `store-icon-128.png` | 128×128 (96px artwork, 16px padding) |
| Screenshots (up to 5) | `screenshot-1-typing.png` … `screenshot-5-anywhere.png` | 1280×800 |
| Small promo tile (required) | `promo-small-440x280.png` | 440×280 |
| Marquee promo tile (optional) | `promo-marquee-1400x560.png` | 1400×560 |
| Promo video (optional) | `video/typinground-demo.mp4` | 1280×800, 8 s, 30 fps |

Upload screenshots in numbered order; the first one is the most visible.

The Chrome Web Store takes the promo video as a **YouTube link**, not a file. Upload `typinground-demo.mp4` to YouTube (Public or Unlisted both work) and paste the URL. `video/demo-poster.png` works as the YouTube thumbnail.

## Firefox Add-ons

Firefox takes screenshots of any size: upload the same five `chrome/screenshot-*.png` files. The icon comes from the extension itself, and there are no promo tiles or video fields.

## Elsewhere

The demo video also fits the landing page or social posts. It loops cleanly from the end card back to the start.
